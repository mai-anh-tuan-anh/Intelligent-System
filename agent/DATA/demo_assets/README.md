# AGENT02 demo assets

- `model.json`: trained baseline Q table and greedy policy; no ML training needed to read.
- `qlearning_model.npz`: same Q table in NumPy format.
- `config.json`: reproducible experiment settings.
- `metrics.json` and CSV files: measured values for dashboard charts.
- `policy_inference.py`: simple inference function for an API.

The environment is simulated; no real sales data is represented.
