# Assignment 04 Web Demo

This Flask website loads the trained artifacts generated by `CNN_Assignment_A_to_Z.ipynb`.

## Put the folder into your project

Copy the `web` folder into:

```text
assignment 4/
├── data/
├── models/
├── outputs/
├── notebooks/
└── web/
```

The app expects the notebook to have produced these files under `models/` (or `models/final/`):

```text
mnist_cnn_scratch.joblib
mnist_cnn_pytorch.pth
mnist_cnn_keras.keras
cifar10_cnn_scratch.joblib
cifar10_cnn_pytorch.pth
cifar10_cnn_keras.keras
diabetes_mlp_scratch.joblib
diabetes_mlp_pytorch.pth
diabetes_mlp_keras.keras
diabetes_standard_scaler.joblib
```

It also reads:

```text
outputs/metrics/*.json
outputs/predictions/*.csv
```

## Install in the CNN conda environment

```bash
conda activate CNN
cd "D:\path\to\assignment 4"
pip install -r web\requirements.txt
```

## Run

```bash
python web\app.py
```

Open:

```text
http://127.0.0.1:5000
```

## Demo features

- Dashboard with the three datasets.
- MNIST image prediction with Scratch, PyTorch and Keras.
- CIFAR-10 image prediction with Scratch, PyTorch and Keras.
- Diabetes prediction with Scratch, PyTorch and Keras MLPs.
- Probability distribution for every class.
- Confusion matrices from notebook prediction outputs.
- Accuracy and Macro F1 charts.
- Parameter-count and training-time comparison.
- Framework explanation aligned with Lecture 04.

The website does not retrain models. It only loads the artifacts from the notebook.
