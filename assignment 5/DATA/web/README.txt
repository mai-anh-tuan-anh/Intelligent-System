A5 CNN Studio - Local Dashboard
================================

This is a local Flask dashboard designed around the final Assignment 05 notebook.
It does NOT retrain models. It loads the saved .keras / .pth checkpoints, the
Diabetes preprocessing artifact, and the experiment metrics generated by the notebook.

1. Put app.py, templates/, requirements.txt in the Assignment 5 project root.
   Recommended structure:

   assignment 5/
       app.py
       models/
       data/
       outputs/
       templates/
           index.html

   A standalone cnn_dashboard folder also works if A5_PROJECT_ROOT points to the
   Assignment 5 directory.

2. Open the project folder in VS Code terminal.

3. Install the small web dependency set if needed:

   pip install -r requirements.txt

4. Run exactly:

   python app.py

5. Open:

   http://127.0.0.1:5000

Optional:
   set A5_PROJECT_ROOT=C:\path\to\assignment 5
   python app.py

Dashboard sections
------------------
Overview
- experiment summary
- accuracy / macro-F1 charts
- dataset cards

Model Lab
- Fashion-MNIST / CIFAR-100 image upload
- TensorFlow or PyTorch
- CNN3 or CNN5
- top-k probabilities and confidence
- architecture visualization

Diabetes Lab
- all 45 processed input features from diabetes_preprocessor.joblib
- sample-encounter autofill
- TensorFlow / PyTorch and CNN3 / CNN5
- class probability chart
- explicit educational/non-clinical disclaimer

Experiments
- filter the notebook's all_experiments_summary.csv
- metric chart
- parameter / training-time chart
- full experiment table

Artifacts
- model-file presence checks
- supporting artifact checks
- run_config.json
- saved notebook figures

Troubleshooting
---------------
"Model artifact not found": run the notebook training cells first so the .keras/.pth files exist.
"Missing diabetes_preprocessor.joblib": re-run the notebook cell that saves the Diabetes preprocessor.
If the app starts from another directory, either cd to the Assignment 5 root or set A5_PROJECT_ROOT.

Medical note
------------
The Diabetes section is an educational inference demo based on the assignment's Conv1D
adaptation of tabular features. It must not be presented as a clinical decision system.
